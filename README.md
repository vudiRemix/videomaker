# videomaker

`split_with_banner.py` делит MP4-видео на части по одной минуте и в каждой части
запускает баннер на **15-й, 30-й и 45-й секунде**.

Баннер — это mp4-ролик со звуком (или картинка). Ролик накладывается поверх
видео и каждый раз проигрывается с начала, а его звук подмешивается к звуку видео.

## Что нужно

- Python 3.8+
- [ffmpeg](https://ffmpeg.org/download.html) (`ffmpeg` и `ffprobe` должны запускаться из командной строки)

## Использование

```bash
python split_with_banner.py video.mp4 banner.mp4
```

Части сохранятся в папку `video_parts` рядом с видео:
`video_part_001.mp4`, `video_part_002.mp4`, …

### Примеры

```bash
# Баннер в правом нижнем углу, шириной 40% кадра
python split_with_banner.py video.mp4 banner.mp4 --position bottom-right --width 0.4

# Баннер на зелёном фоне (хромакей): зелёный станет прозрачным
python split_with_banner.py video.mp4 banner.mp4 --chromakey

# Приглушить звук видео до 30%, пока играет баннер
python split_with_banner.py video.mp4 banner.mp4 --main-volume 0.3

# Баннер на весь кадр
python split_with_banner.py video.mp4 banner.mp4 --position full

# Другие секунды показа и своя папка
python split_with_banner.py video.mp4 banner.mp4 --times 10,40 -o parts

# Картинка вместо ролика, 5 секунд
python split_with_banner.py video.mp4 banner.png --image-duration 5
```

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `-o`, `--output-dir` | `<имя>_parts` | папка для частей |
| `--times` | `15,30,45` | секунды внутри каждой части, когда запускается баннер |
| `--segment` | `60` | длина части в секундах |
| `--position` | `center` | `top`, `bottom`, `center`, `top-left`, `top-right`, `bottom-left`, `bottom-right`, `full` |
| `--width` | исходный размер | ширина баннера в долях ширины видео (`0.4` = 40%) |
| `--margin` | `0.05` | отступ от края в долях высоты видео |
| `--chromakey [ЦВЕТ]` | выкл. | убрать фон баннера этого цвета (без значения — зелёный `0x00FF00`) |
| `--key-similarity` | `0.3` | насколько близкие к фону цвета тоже убирать |
| `--banner-volume` | `1.0` | громкость звука баннера |
| `--main-volume` | `1.0` | громкость видео, пока играет баннер |
| `--image-duration` | `5` | сколько секунд показывать баннер-картинку |
| `--crf` | `20` | качество видео (меньше — лучше и тяжелее, обычно 18–28) |
| `--preset` | `veryfast` | скорость кодирования x264 (`ultrafast` … `veryslow`) |

## Как это работает

- Видео режется точно по минутам; последняя часть — остаток (может быть короче минуты).
- В короткой последней части баннер запускается только на тех секундах, которые в неё попадают.
- Если баннер длиннее 15 секунд, показы будут накладываться друг на друга — скрипт об этом предупредит.
- Видео перекодируется в H.264, звук — в AAC 192 кбит/с.
