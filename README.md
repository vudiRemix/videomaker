# videomaker

Делит видео на части по одной минуте и в каждой части вставляет баннер
на **15-й, 30-й и 45-й секунде**.

Баннер — ролик `banner.mp4` (manulcraft.com, 3,6 с, со звуком) уже лежит в проекте.
Его зелёный фон вырезается автоматически, так что вокруг карточки видно основное видео.
Звук баннера подмешивается к звуку видео.

## Как пользоваться (Windows)

1. Скачайте проект: на GitHub нажмите **Code → Download ZIP** и распакуйте.
2. Положите свои видео в папку **`input`**.
3. Дважды щёлкните **`run.bat`**.
4. Заберите готовые части из папки **`output`**: для каждого видео своя подпапка
   с файлами `имя_part_001.mp4`, `имя_part_002.mp4`, …

При первом запуске `run.bat` проверит Python и ffmpeg. Если их нет, он предложит
установить их сам (через winget). После установки закройте окно и запустите `run.bat` ещё раз.

**Другие способы:**

- **Перетащите видео на `run.bat`** — обработаются именно эти файлы, где бы они ни лежали.
- **`watch.bat`** — режим «поставил и забыл»: окно следит за папкой `input`,
  и каждое новое видео обрабатывается само, как только докопируется. Выход — Ctrl+C.

Уже обработанные видео при повторном запуске пропускаются, поэтому можно просто
докладывать новые файлы в `input` и снова запускать `run.bat`.

## macOS / Linux

Нужны Python 3.8+ и ffmpeg (`brew install ffmpeg` или `sudo apt install ffmpeg`).

```bash
./run.sh                  # обработать папку input
./run.sh video.mp4        # конкретные файлы
./run.sh --watch          # следить за папкой input
```

## Настройки

Любой параметр можно добавить к запуску:
`run.bat --main-volume 0.3` или `python split_with_banner.py --main-volume 0.3`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--banner` | `banner.mp4` | другой баннер: видео или картинка (png/jpg) |
| `--times` | `15,30,45` | секунды внутри каждой части, когда запускается баннер |
| `--segment` | `60` | длина части в секундах |
| `--position` | `center` | `top`, `bottom`, `center`, `top-left`, `top-right`, `bottom-left`, `bottom-right`, `full` |
| `--width` | исходный размер | ширина баннера в долях ширины видео (`0.4` = 40%) |
| `--margin` | `0.05` | отступ от края в долях высоты видео |
| `--chromakey` | `auto` | `auto` — найти и вырезать зелёный/синий фон, `off` — не вырезать, или цвет `0x00FF00` |
| `--key-similarity` | `0.15` | насколько близкие к фону цвета тоже вырезать |
| `--banner-volume` | `1.0` | громкость звука баннера |
| `--main-volume` | `1.0` | громкость видео, пока играет баннер (например `0.3`) |
| `--image-duration` | `5` | сколько секунд показывать баннер-картинку |
| `--input-dir` | `input` | откуда брать видео |
| `-o`, `--output-dir` | `output` | куда сохранять части |
| `--watch` | — | следить за папкой и обрабатывать новые видео |
| `--force` | — | обработать заново уже готовые видео |
| `--crf` | `20` | качество видео (меньше — лучше и тяжелее, обычно 18–28) |
| `--preset` | `veryfast` | скорость кодирования x264 (`ultrafast` … `veryslow`) |

Чтобы сменить баннер насовсем, замените файл `banner.mp4` на свой.

## Как это работает

- Видео режется точно по минутам; последняя часть — остаток (может быть короче минуты).
- В короткой последней части баннер запускается только на тех секундах, которые в неё попадают.
- Баннер больше кадра уменьшается до размеров видео; в вертикальном видео он вписывается по ширине.
- Видео перекодируется в H.264, звук — в AAC 192 кбит/с.
- Готовность видео отмечается файлом `output/<имя>/.done`; удалите его или запустите с `--force`, чтобы переделать.
